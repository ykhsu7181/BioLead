## 4. 当前主要限制

- 当前不是生产系统。
- PubMed 是主链路，其他数据源仍需继续补齐字段和 adapter 标准化。
- 多源身份归并仍保守，不能只凭姓名合并。
- 邮箱只来自公开证据，不补猜。
- 邮件发送必须人工审核和受控执行，不允许 Agent 无人值守发送。
- Vue 前端仍在迁移中，Streamlit 原型仍保留。
- 生产级部署、权限、审计、退订、退信、限流和 CRM 尚未完整实现。

## 5. 当前验收结论

截至 Stage 38，项目已经完成第一版科研线索发现、证据记录、邮件草稿、受控发送、结果包和前后端骨架。

下一步开发应从 Stage 39 开始，在现有架构上增强业务闭环、Vue 功能迁移、生产级邮件治理、多源数据源扩展和 CRM/跟进能力。
