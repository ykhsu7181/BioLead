## 1. 状态定义

- 已完成：当前仓库已有实现和测试。
- 开发中：已有部分原型，但未达到完整验收标准。
- 待开发：尚未实现。
- 受限：受账号、费用、合规或第三方规则限制。
- 需甲方配合：需要甲方提供资料、账号、样本或确认。

## 4. 第一轮 PubMed 验收标准

第一轮只针对 PubMed，建议验收：

- 输入关键词后能创建检索任务。
- 能通过 PubMed ESearch 获取 PMID。
- 能通过 PubMed EFetch 获取 XML。
- 原始响应保存到 `data/raw/pubmed`。
- 能解析 PMID、DOI、标题、摘要、期刊、发表日期、作者、机构。
- 能从 affiliation 中提取公开邮箱。
- 邮箱必须保留来源链接。
- 无邮箱时标记 `missing`。
- 能生成 PI/通讯作者候选线索。
- 能输出 PubMed 单源临时评分。
- 能导出 JSON/CSV。
- 测试中模拟 HTTP，不访问真实网络。
