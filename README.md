# Literature AI Agent

## 项目目标

开发一个简单的文献分析 AI Agent。

用户输入研究关键词后，系统执行：

1. 调用 OpenAlex API 检索论文；
2. 获取标题、DOI、摘要、作者、单位和发表日期；
3. 按 DOI 去重；
4. 调用大语言模型分析研究方向和技术路线；
5. 根据公司产品表推荐可能相关的服务；
6. 生成邮件草稿；
7. 邮件只保存为草稿，不自动发送。

## 第一版不做

- 不抓取非开放获取全文；
- 不猜测缺失的作者邮箱；
- 不自动发送邮件；
- 不自动连续跟进；
- 不训练或微调大模型；
- 不使用复杂的多 Agent 架构。

## 技术选择

- Python 3.11
- requests
- pandas
- SQLite
- Streamlit
- OpenAlex API
- LLM API

## 输入

- 检索关键词
- 起始日期
- 结束日期
- 最大论文数量

## 输出

- OpenAlex ID
- DOI
- 标题
- 摘要
- 作者
- 单位
- 发表日期
- AI研究方向分析
- 技术路线
- 潜在需求
- 匹配产品
- 邮件草稿

## 开发顺序

1. 初始化项目；
2. 接入 OpenAlex；
3. 保存原始 JSON；
4. 数据清洗和 DOI 去重；
5. 接入 Crossref；
6. 接入 LLM；
7. 产品匹配；
8. 邮件草稿；
9. Streamlit 页面；
10. 人工审核功能。
